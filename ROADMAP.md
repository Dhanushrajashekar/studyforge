# StudyForge roadmap

This roadmap is aspirational; it does not represent existing features.

## Released: v1.1
- 30 JavaScript challenges, three difficulty levels
- Topic-based learning paths (Strings, Arrays, Logic, Math, Objects)
- Automatic JavaScript test feedback in sandboxed iframes
- Local progress and draft persistence, export and import
- GitHub Actions checks and GitHub Pages publishing workflow

## Next milestones
1. Invite educators and learners to review wording and test edge cases.
2. Add accessibility improvements and mobile browser testing.
3. Expand challenge authoring guidance and test coverage.
4. Add optional language translations through community contributions.
5. Explore Python and SQL support only after implementing suitable safe runtimes and test infrastructure.

## Useful project metrics
Track only actual public evidence, such as releases, confirmed external contributors, issue response times, and voluntary user feedback. Do not fabricate GitHub activity or usage numbers.
