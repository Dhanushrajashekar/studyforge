# Security policy

StudyForge runs user-written JavaScript inside a sandboxed, opaque-origin iframe with a restrictive Content Security Policy. This is **not** a hardened environment for executing hostile code. Run only code you understand; do not paste passwords, API keys, or sensitive information into the editor.

Drafts and completion progress are saved in the browser's local storage. StudyForge has no user account system or server-side storage. Exported progress files may contain your code drafts: review them before sharing.

If you find a security problem, avoid publishing exploit details in a public issue. Contact the repository maintainer privately via their GitHub profile, if contact details are provided.
